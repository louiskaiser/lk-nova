构造
主干基于矩形，字腔由圆润的轮廓构成。曲线以相切方式衔接，并通过视觉超出量协调圆形与平直形态。
大小写字母采用统一的比例和构造原则。Λ 和 Ξ 为 LOUIS KΛISΞR 品牌名单独提供，A 和 E 保持不变。

起源
LK Nova 为 Louis Kaiser 的品牌形象而设计。其粗体无衬线比例和紧凑字距以 Helvetica Neue 为视觉参考。
轮廓根据几何形状独立构建，并通过多轮审查完善曲线、字腔、数字和连接处。未包含第三方字体轮廓。


字符集
包含拉丁字母、其他欧洲字符、数字、标点和部分符号，包括 Λ、Ξ、⇒ 和 ■。不包含中文字形。

使用 LK Nova
安装
在 macOS 的字体册或 Windows 的“安装”中添加 Desktop/Variable/LKNova-VF.ttf。不支持可变字体的应用可使用六款静态字重。建议选择可变或静态字体系列之一，以避免重复条目。
品牌设置
字重 900，字宽 100，直立，字距 −0.05 em（以千分之一 em 为单位时为 −50）。LK Nova 用于展示和标题，长篇正文请使用其他正文字体。
网页与动画
将 font.css 与 LKNova-VF.woff2 放在同一目录，并使用 lk-display 类。可变轴和彩色字体的支持情况取决于应用。另附红色方块 SVG。动画示例遵循减少动态效果的偏好。
许可
可免费用于个人及商业项目，允许安装、嵌入、修改和再分发。无需署名、版税或按席位付费。字体许可不授予 LOUIS KΛISΞR 品牌权利。
