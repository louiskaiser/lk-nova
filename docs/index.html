Construction
Rectangles define the stems; rounded contours define the bowls. Tangent transitions join the curves. Optical overshoot aligns rounded and flat forms.
Uppercase and lowercase letters share the same proportions and construction principles. Λ and Ξ are separate characters for LOUIS KΛISΞR; A and E remain unchanged.

Origins
LK Nova was developed for Louis Kaiser’s brand identity. Helvetica Neue was a visual reference for its bold grotesk proportions and tight spacing.
The outlines were constructed independently from geometric shapes and refined through successive reviews of curves, counters, numerals and joins. No third-party font outlines are included.


Character set
Latin letters, additional European characters, numerals, punctuation and selected symbols, including Λ, Ξ, ⇒ and ■.

Using LK Nova
Installation
Install Desktop/Variable/LKNova-VF.ttf with Font Book on macOS or Install on Windows. Use the six static weights for applications without variable-font support. Install either the variable or static family to avoid duplicate entries.
Brand settings
Weight 900, width 100, upright, tracking −0.05 em (−50 in 1/1000-em units). LK Nova is a display face; use a separate text face for longer reading.
Web & animation
Keep font.css beside LKNova-VF.woff2 and apply the lk-display class. Variable-axis and color-font support depend on the application. A red square SVG is included as an alternative. Animation examples respect reduced-motion preferences.
